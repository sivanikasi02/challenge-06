Algorithm 

1.Start.
2.Display the menu:
 Solve a linear equation
 Calculate factorial
 Solve a quadratic equation
 Exit
3.Read the user's choice.
4.If choice is 1:
 Read a and b.
 If a != 0, calculate x = -b/a.
 If a = 0 and b = 0, display infinitely  many solutions.
 Otherwise, display no solution.
5.If choice is 2:
 Read integer n.
 If n is between 0 and 12, calculate  factorial using a loop.
 Otherwise, display an invalid value  message.
6.If choice is 3:
 Read a, b, and c.
 If a = 0, display that it is not a quadratic equation.
 Otherwise, calculate discriminant D = b² − 4ac.
 If D > 0, calculate two distinct real roots.
 If D = 0, calculate equal real roots.
 If D < 0, display no real roots.
7.If choice is 4, display the closing message and stop.
8.If the choice is invalid, display an error message.
9.Repeat the menu until Exit is selected.
10.Stop.
